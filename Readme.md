## Sobre el juego

> **El teléfono suena. Hay un gato atorado en un árbol. El cronómetro ya empezó.**

Manejas la única camioneta de rescate felino del pueblo. Las llamadas no paran: llega hasta cada emergencia, rescata al gatito y vuelve a la veterinaria antes de que se acabe el tiempo.

Cada segundo cuenta. **Salva a todos los gatitos que puedas.**

## Objetivo

1. Atiende las llamadas de rescate.
2. Conduce hasta el gato que necesita ayuda.
3. Rescata al gato.
4. Regresa a la veterinaria antes de que termine el tiempo.
5. Supera tu récord de rescates.

## Controles

| Acción | Tecla |
| :-- | :--: |
| Avanzar | `W` |
| Girar a la izquierda | `A` |
| Girar a la derecha | `D` |
| Frenar / reversa | `S` |

## Ejecutar el proyecto

1. Abre la carpeta del proyecto con **Unity 6** (`6000.3.7f1`) o una versión compatible.
2. Espera a que Unity importe los recursos.
3. Abre la escena principal desde la carpeta `Assets/Scenes` y presiona **Play**.
